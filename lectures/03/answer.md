# 第3回 解答

## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは「レベル1・2・3」など一般論を答えた。エージェントは用語集を検索して「基礎・実装・発展」と、どれか1つで完了というルールまで正しく答え、「関連する回：第1回」も示した。
- `--trace` で見えたツール呼び出し（ツール名と引数）：search_glossary({'query': 'LoRA'}) と search_glossary({'query': 'QLoRA'}) が別々に呼ばれた。
- 1つの質問での LLM 呼び出し回数（`requests`）：LoRAとQLoRAの質問で requests=2, tool_calls=2。確認問題の質問では requests=2, tool_calls=1。
- 追加したツールと、docstring に書いた説明：make_quiz(lecture: int) を追加。docstringに「復習用の確認問題を出したいときに使う（例：第2回の確認問題を出して）」と書いた。「モデルに見えているツール」は3個になり、make_quiz({'lecture': 2}) が呼ばれることを確認し、pytest は11 passed。

## 宿題

- 取り組んだレベル：基礎 
- やったこと：同じ質問「LoRAとQLoRAの違いは？」を --trace 付きで3回実行した。1回目は何も変えずに実行（ベースライン）。2回目は app/agent.py の INSTRUCTIONS から「用語や講座に固有のことを答える前に、必ず search_glossary で用語集を確認する」の行だけを削除した。3回目は、2回目の変更を元に戻したうえで、app/tools.py の search_glossary の docstring から「答える前に使うこと。」の一文だけを削除した。一度に変えるのは1か所だけにした。
- 結果：

  | 条件 | tool call | requests / tool_calls | input / output トークン | 回答の書き出し |
  |---|---|---|---|---|
  | ベースライン | LoRA・QLoRAを各1回検索 | 2 / 2 | 1364 / 180 | 要約して説明 |
  | INSTRUCTIONSの行を削除 | 同じ | 2 / 2 | 1316 / 167 | 「用語集によると」 |
  | docstringの一文を削除 | 同じ | 2 / 2 | 1352 / 201 | 「講座の用語集によると」 |

- 気づき・疑問：「必ず検索」の行を消せば検索しなくなると予想したが、検索は変わらず2回呼ばれた。指示が2か所（INSTRUCTIONS と docstring）にあり、片方を消してももう片方が残るため、またはツール名や説明の冒頭の「用語集から用語を検索し…」だけでも使われたと考えられる。両方を同時に消すと変わるのか、用語集にない言葉を質問した場合はどうなるのかを試したい。回答の書き出しや出力トークン数の違いは、1回ずつの比較では、変更の効果か実行ごとのばらつきか判断できなかった。
